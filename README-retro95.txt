Retro Windows Workstation
Open windows95.html directly for the standalone desktop. For installable PWA/offline caching and reliable local storage, put all bundle files in the same directory and serve them over HTTPS or localhost (for example: python -m http.server 8000; visit http://localhost:8000/windows95.html). Install from the browser menu when available. Music streaming requires internet and YouTube embedding permission. External disk saving requires supported browser file picker permissions. Export backups before changing browser/origin. Other Windows versions are shell themes, not full systems. Game demos are original simplified adaptations, not original executables. Actual x86 emulation requires user-provided libv86.js and v86.wasm next to the HTML plus BIOS ROMs and licensed boot media; not runtime-tested. No licensed Windows files are provided.

Focus & Productivity: Sticky Notes and Pomodoro Timer are in Start > Programs. Notes are saved per local profile with their color and desktop positions; closing a note hides it. The timer continues while minimized or closed within the desktop and uses a saved deadline to reconcile an elapsed interval on reopening. Completion sounds depend on browser audio permission.
